# API リファレンス

現時点の実装は **フェーズ1（MVP）** であり、REST API は未実装です。  
Flask サーバーが提供するエンドポイントは以下の1つのみです。

---

## ページ配信エンドポイント

### `GET /`

Pomodoro タイマーの初期画面（`index.html`）を返します。

- **レスポンス**: `text/html` — `templates/index.html` をレンダリングした HTML
- **ステータスコード**: `200 OK`

---

## 未実装（フェーズ2 予定）

以下の API は設計書には記載されていますが、現時点では実装されていません。

| エンドポイント | メソッド | 概要 |
|---|---|---|
| `/api/settings` | `GET` | 設定の取得 |
| `/api/settings` | `PUT` | 設定の更新 |
| `/api/sessions` | `POST` | セッション完了記録の作成 |
| `/api/sessions` | `GET` | 期間指定での履歴取得 |

---

## サーバー起動設定

| 項目 | 値 |
|---|---|
| ホスト | `0.0.0.0` |
| ポート | `5000` |
| デバッグモード | 環境変数 `FLASK_DEBUG` が `1` / `true` / `yes` / `on` のとき有効 |

依存ライブラリ: `Flask>=3.1,<4.0`
